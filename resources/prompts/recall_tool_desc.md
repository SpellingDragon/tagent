Intelligent memory recall tool. Queries historical events and synthesizes memories into coherent responses.

1. Natural language queries: ask about past events in plain language
2. Event type filtering: filter by external_input, agent_output, action_command, etc.
3. Detailed retrieval: get full event content by event key
4. Recent events: quickly access the most recent memories

The agent understands your query and uses the appropriate tools to retrieve relevant memories.
