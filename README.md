# tagent

A new agent project based on event-driven architecture.

## Overview

tagent is a Go-based agent framework that embraces a fully event-driven, memory-centric design philosophy.

## Getting Started

### Prerequisites

- Go 1.21 or higher

### Project Structure

```
tagent/
├── go.mod          # Go module definition
├── .gitignore      # Git ignore rules
└── README.md       # This file
```

## Development

```bash
# Build
go build ./...

# Test
go test ./...

# Run
go run .
```
