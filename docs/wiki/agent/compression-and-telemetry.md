# 上下文压缩、会话投影与自身遥测

本页承载 `agent/compress` 一侧的判据：预算不足时**保留什么、丢掉什么**如何可核查，投影折叠为何不能重复，以及"内部状态要不要外显"由什么决定。三件事的共同点是失效都不报错——只会**悄悄丢内容**、**重复注入同一条事实**，或**长期沉默无人察觉**。

<a id="condensed-card-guard"></a>
## 一、综述卡片必须机器校验，票据不得凭空出现

压缩产出的一行综述卡片在采纳前逐项比对被折叠掉的输入行，判据三条：

| 判据 | 为什么 |
|---|---|
| 输出票据 ⊆ 输入票据 | 伪造的票据会进入 compaction 载荷，**污染其后每一次召回**（召回出来的"原文"根本不存在） |
| 头、尾与每个 ★ 高亮行的票据都必须存活 | 它们是导航锚点与长期反思结论，丢了就等于把"去哪找"抹掉 |
| 输入含票据而输出一个都没有 ⇒ 拒绝 | 这是票据全丢，不能被当成"压缩得很彻底" |

两条边界：输入本身不含可解析票据（散文类样本）时**不拒绝**——守卫只约束真实票据；整个校验零 LLM 调用、零存储读取，因此可以在每次产出上无条件跑。

<a id="projection-fold"></a>
## 二、会话投影是"可回放折叠"，不是历史缓冲

装配上下文读的是投影，事件全量另存于记忆存储。三条约束：

- **带键事件幂等追加**：同一 `EventKey` 第二次追加被跳过并告警——重复投影会让同一条事实出现在上下文两次；无键（`EventKey==0`）不参与去重，总是追加；
- **重建按当前引用整表重算**去重键集，因此被折叠掉的键会随之离开键集，键集大小只随重建有界（若沿用旧集合，它只增不减）；
- **读取返回拷贝**：装配侧改写结果不会影响投影内部状态；
- **无锚点链回退时先过滤、后截断**：完整分页重放必须先滤掉非投影记录，再保留最新的 N 条有效事件。顺序反了（先取 N 条再过滤）会让登记与内部回执记录把真实历史挤出去——名义上"重建了最近窗口"，实际只剩回执。

排除"哪些记录不进投影"的判定只有**一个来源**（事件类型注册表提供的谓词），与正常提交、冷启动重建共用同一处。各处自带类型枚举，就会漏排内部回执，把回执注进投影，破坏"投影＝事实链可回放折叠"这条不变量。

<a id="telemetry-ladder"></a>
## 三、自身遥测的可见性是分档升降的，不是一刀切

内部状态要不要外显为宿主可见的提示，由滑动窗口样本决定：窗口时长、负例占比阈值、最少样本数、每档驻留时间都是命名常量。两端要防的风险分别是"**看一眼就永久外显**"（噪声淹没宿主）与"**长期沉默无人察觉**"（降级一直发生却没人知道）。

统计口径本身要收窄：只计入**自管谱系**（冥想、任务退役、未知来源）——这些产出不是用户发起的交互；判据与投递门使用**同一份**负例清单，两处各写一份必然分叉。

<a id="output-overflow"></a>
## 四、工具结果超限：内联留摘要，全文转储并留票据

超限时不是截断丢弃，而是**内联留可读摘要 ＋ 全文转储为文件 ＋ 票据可找回原文**。两条约束：

- **内联上限与 token 预算解耦**：按 `MaxTokens/2*4` 一类的公式派生，会在 128K 预算下算出约 256K 字符——那是一个无人负责的公式后果，不是策略；
- **转储绝不阻塞主循环、绝不静默丢弃**：消费者停滞时也要落盘并留票据，与结算大结果转储同构。

声明侧对未超限结果透传；`nil` 结果与结构体结果都必须有确定行为，不能靠"看起来是空"来推断。

<a id="self-state-digest"></a>
## 五、自我状态摘要：呈现必须有界，且被裁掉的数量要显式报出

冥想前注入的自我状态摘要受三条界约束：需关注项（可疑／已死／失败）**最多展示固定条数**，描述**按 rune 截断**（按字节截断会切坏中文），被截掉的数量必须以"共 N"显式报出而不是静默省略；状态按**固定顺序**聚合计数，避免同一份状态每次渲染顺序不同。

没有控制器时，整段摘要**缺席**，而不是产出一个空壳段落——空壳会让模型以为"看过且无事"。

<a id="hot-bundle-atomicity"></a>
## 六、热参必须一次读全，不能逐字段取

压缩边界要用的那组数值（触发线、内层目标、以及与之配套的一项开关）**必须由一次读取整体取出**，因此外层触发线与内层压缩目标一定来自同一代。逐字段各自读取会跨代撕裂：先读到新代的触发线、后读到旧代的目标值，预算判定就落在一对从没同时存在过的参数上——这种错不会报错，只会让压缩"看着不该发生却发生了"或反之。取不到有效值（零或非法）时回落到构造期的值：一个还没有任何记录的属主也必须算得出合理预算，不能因缺值而不出预算。

## 已知缺口与演进方向

- 守卫拒绝时只返回理由文本，缺一个"哪条票据丢了"的可枚举输出，排查要靠人读日志；
- 投影键集有界依赖整表重算，重建成本随活跃引用数线性，尚无实测上限；
- 遥测阶梯的占比与驻留参数缺跨场景标定（高频短回合与长驻留任务的节奏差别很大）。
