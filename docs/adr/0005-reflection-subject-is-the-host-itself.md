# 反思主体是宿主自身：自察为缺省，独立策展为显式选项

**Status**: accepted（2026-11-05 用户裁决，boundary-closure r14；实施在 changes/09-meditation-autonomy/ 任务 1.3a2）

曾以独立 meditator agent 作为 wechat-bot 的冥想部署形态，理由是上下文隔离（反思噪音不进用户会话）、第二循环、最小权限、血统隔离。本裁决推翻该缺省：独立形态有两个致命代价——

1. **只能反思影子**：上下文隔离使 meditator 的材料只能是 digest（摘要＋事件键），它从未在场，看不到对话脉络与工具调用的来龙去脉；recall 可按图索骥，但不是拥有完整上下文的反思。
2. **教训落在别人记不住的账上**：经验卡片进冥想者的分区与记忆，宿主永远记不住自己的教训（send 注入一次性）——"经历→教训→下次更好"的自我改进闭环在结构上断裂：反思者与使用者不是同一个记忆体。

定案：**冥想插件缺省挂宿主 agent 自身**（规格既有"缺省自察"形态）——同会话反思：完整（窗口化）上下文在望；经验卡片落己链＝己记忆，与历史一同折叠；空闲门＋决策席抑制防干扰；自管谱系在同 agent 内同样防永动；09 的自主整理工具面（file/exec/recall/refine）天然可用。独立 agent 降格为**显式声明的跨域策展选项**（一专职策展者观察多分区；读别人＝摘要＋回查是跨域固有属性，不是反思自家行为的缺省形态）。旧四理由在自察下全部消解或降为次要（污染→折叠管；干扰→席位抑制；权限→纪律靠提示词与安全门而非工具饥饿；血统→同 agent 内成立）。

- **代价与取舍**：自察使反思与业务共享上下文预算（窗口压力增大，靠折叠与卡片有界性管理）；换来完整上下文与教训入己记忆的完整学习闭环。
- **不做的事**：不废除独立策展形态（配置选项保留）；不改变状态机/能量守恒/send 门语义——变的只是缺省主体。
- **依据**：用户裁决（r14：独立 agent 因上下文隔离无法有效反思）；规格既有缺省自察条款（meditation-agent-partition）；自我改进引擎愿景（self-improvement-meditation）要求教训可积累于行为主体。
