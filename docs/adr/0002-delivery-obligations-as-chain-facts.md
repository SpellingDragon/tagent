# 交付义务走链上事实（机制事件化），不再用旁路 KV 欠条

**Status**: accepted（2026-11-05 用户终裁，boundary-closure r1 三轮追问后定案；实施在 `openspec/changes/archive/2026-11-05-01-delivery-closure/`）

交付义务（"这笔答案欠某个外部渠道一次发送"）此前记在旁路 KV 账本（`tagent/task/v1/delivery:`），与事实链分离。两条路摆在面前：**A** 保持两本账+启动对账（小切口：恢复时扫链补建缺失欠条）；**B** 机制事件化（交付义务成为链上事实族，随 `agent_output` 同笔原子提交，发送/重试/审批由消费挂点驱动）。用户选 **B**。

选 B 的理由：一是**构造性闭合**——义务与答案同一笔提交，"有答案无欠条"的悬空状态从根上不可能出现，而 A 只靠对账不变量守护接缝；二是**符合系统的扩展思想**——"一条链、三个挂点"（事件生产→插件管线→读链消费）是本仓特性的首选扩展轨道，压缩请求/产物（事实族 7/8 → CompressionConsumer）已是成熟先例，交付是最后一块还在旁路账本上的机制。代价如实记录：刚完成收敛（170ef267）的运行时再做一次交付路径大迁移，改动面大、风险集中；链会变重（每笔外发多 1–2 条小事实），须以"义务事实要小、豁免折叠、斜率门兜底"守住"链保持轻"的纪律；概念文档（机制导览/执行核架构把「交付结算态」划在账本层）须同步改。

- **感知/表达/兜底三层（r1 追问六裁定；grill r1 F2/r2 F1 统一口径；r5 收敛）**：交付**结算事实**（各结算态）必达模型消费与投影呈现（回执事件同族待遇——感知是构造保证，投影侧由类型→角色映射提供呈现）；**owed 声明随 agent_output 本体呈现，无独立可见面**；**对用户如何表达由模型自主选择**，框架不写死"请重问/稍后补送"类文案；**管道记账噪音**（重试计时、中间探测）不进投影；**兜底两支（与 01 spec 一致；r8 F1 定版）**：① **失败告知**——failed 终态→既有 failure-notice 照发（failed+无正文+有原因，**无义务条件**）；② **延迟告知**——**存在未清 held 交付义务 × 该义务的驱动轮结束无面向用户产出**→01 新增恰一条最小延迟告知，**话术按 held.reason 分层**（`retrying`→稍后必补送；`approval`/`unknown`/`retry-exhausted`→已转人工处置），MUST NOT 与模型产出重复；支②不是失败告知，failure-notice 只管辖支①——01 以一条 MODIFIED 给「成功但无正文保持静默」场景加豁免句（未清 held 义务时按延迟告知恰发一条、非失败话术），不新增通道、不改 failed 触发条件；且支②不以“成功终态”为前置（body 存在⇒owed 在链上，该前提不可达）；**悬空无终态不发框架通知**。
- **不做的事**：不把**管道记账噪音**（重试计时、中间探测、迁移记账）呈现进模型投影可见面——状态变化事件本身是要呈现的（见上条）；不试图消灭"已发出、销账未落"的窗口——它是一切至少送达一次系统的固有形态，靠义务身份去重兜底；不立即删除旧 KV 记录（迁移后只读留存）；不留逃生开关——事件化是唯一路径（r22 纯化）。
- **前提纪律**：结果未知（超时/中断/不可辨）的发送不自动重发（`delivery-dispatch-receipts` 条款继续有效）；明确失败才有界退避自动重试，耗尽落 held 待人工。
- **恢复补送注记（r5；P7-P14 F1 扩围）**：重启补送遵循 **at-least-once**，仅针对**无结算事实 ∪ held(reason=retrying)** 的义务（中断在退避途中的义务重启后续跑，不搁浅；发过未销账窗口内可能重发一次）；**已确认 sent 绝不重发**；收方按交付身份去重是通道契约假设（与 `docs/wiki/reliability/durable-delivery.md` 同义）。
- **实施注记（2026-11-05，01 域落地）**：本裁决实现为 `delivery.settlement` 事实族（键=交付身份+状态，四结算态＋迁移专用 owed 态，held 带 reason∈{approval, retrying, retry-exhausted, unknown}）＋ `DeliveryConsumer` 的自持退避；恢复只读链（结算事实与 owed 声明都取自事实窗口，`delivery.` 前缀过滤**返回集**）、旧 KV 六态幂等迁移为对应事实后只读留存（不可解析具名拒启动）、`TestSettlementRoleMapped` 钉住类型→角色映射。兜底两支分别由失败告知（支①）与延迟告知（支②）承担，锚=`TestNoSilentUndischargedObligation`／`TestDelayedNoticeLayeredByReason`；结果未知不自动重发的负锚=`TestUnknownResultNeverAutoRedriven`。
- **依据**：`docs/wiki/mechanism-tour.md` §2 三个挂点；压缩消费先例（`openspec/specs` 压缩相关能力）；缺口证据 `openspec/changes/archive/2026-11-05-boundary-closure/design.md` D1 E1–E3；用户裁决三轮记录（r1：可靠性优先→两本账追问→三挂点思想确认终裁 B）。
