# 冥想触发是自持状态机，不是虚投影事件

**Status**: accepted（2026-11-05 用户裁决，boundary-closure r11；实施在 changes/09-meditation-autonomy/）

冥想输入曾可以被描述为"虚投影事件插件"：时机到了，把别的链投影成一条自管虚事件投给一个回合。这个描述藏着一个陷阱：**虚事件＝自管谱系＝因果终末**——它喂不醒任何东西（包括自己）。一个只能被外部事件唤起的机制，在结构上没有主动权；"主动反思"名存实亡，且激活方式被锁死在"对别人事件的响应"一种上。

定案模型（电容隐喻）：冥想插件是一个**自持状态机**——外部事件修改状态（充电：novelty 累积、静默窗、欠账计数）；状态达到激活即触发一个**真实事件**（状态激活迁移的投影，携带完整因果：谁充电、哪条规则放电）；冥想回合在独立 session 消费这个真实事件，digest 只是载荷。**定时只是激活检查方式之一**：时间窗、累积阈值、外部请求都是一等激活源。防永动由"事件虚所以不算数"重述为**状态能量守恒**：充电只来自外部、放电即复位、自管产出不给状态充电——永动在状态机层面不可能，不再依赖谱系身份。

- **代价与取舍**：状态机需要持久化与审计（迁移记录），比隐式水位锚重；换来的是主动权、多源激活与完整因果链。
- **规格面后果（r12 补充裁定）**：门＝状态机内部转移规则，不再作为独立主规格（meditation-idle-gating）对外暴露——否则实现细节被冻结成契约，每加一种激活源都要规格手术。对外只留不变量：能量守恒防永动、用户让路、锚点重启安全、触发即真实事件可审计、影响他人只经 send；机制条款（novelty 判定/双锚/rearm/fail-closed）下沉实现文档。五份冥想规格的收敛方向：对外=冥想能力契约＋send 工具契约，内部全下沉。
- **不做的事**：不改变三件套既有语义（独立会话/send 四道门/让位规则在状态机上重述而非废除）；不引入冥想专用回合机制——消费仍是普通回合；自管产出仍不充电。
- **依据**：用户裁决（r11 陷阱分析）；现状实测（隐式状态机＝水位＋在途＋重评定时器，TestTheGateReevaluatesAfterTheWindow 证定时重评已存在）；防永动规格（meditation-idle-gating）在能量守恒表述下等价保持。
