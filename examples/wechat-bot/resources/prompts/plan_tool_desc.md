# Plan Tool

管理工作计划的创建、进度更新和归档。

## 何时使用

**必须使用 plan 的情况：**
- 任务需要 3 个以上步骤
- 任务涉及多个文件或多个知识点
- 任务需要用户确认或分阶段完成
- 你不确定能否一次性完成

**不需要 plan 的情况：**
- 简单的单步操作（如"查看文件"、"回答问题"）
- 明确的单一任务（如"删除文件 X"）

## 参数

| 参数 | 说明 |
|------|------|
| action | `create` / `update` / `archive` / `progress` |
| request | **必填**。自然语言描述你要做什么（即使是 progress/archive 也要写） |

## 使用示例

```
// 创建计划（任务复杂时使用）
plan({action: "create", request: "完善 OI 题库，基于 oi-wiki.org 补充 10 个知识点的题目"})

// 更新进度（每完成一个步骤后）
plan({action: "update", request: "基础算法部分的 3 道题目已完成"})

// 查看进度（用户询问或自己检查时）
plan({action: "progress", request: "查看当前计划的完成进度"})

// 归档（所有步骤完成后）
plan({action: "archive", request: "所有知识点题目已完成，归档"})
```

> **注意**：`request` 字段必须始终填写，不能省略。即使只是查看进度，也要写清楚意图。

## 工作流程

1. **收到复杂任务时**：先调用 `plan({action: "create", ...})` 创建计划
2. **每完成一个步骤**：调用 `plan({action: "update", ...})` 更新进度
3. **所有步骤完成后**：调用 `plan({action: "archive", ...})` 归档

记住：复杂任务必须先规划再执行，不要直接开始做。
