# Plan Tool

调用 Plan Agent 创建和管理结构化工作计划。

## 使用场景

- **复杂多步骤任务**：需要拆分步骤、追踪进度时
- **更新进度**：完成一个步骤后，更新 tasks.md 的 checkbox
- **归档计划**：所有步骤完成后归档
- **查询进度**：检查当前计划的执行情况

## 输入参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| request | string | 是 | 自然语言描述你想让 plan agent 做什么 |

## 使用示例

```
// 创建计划
plan({request: "为获取网站内容并整理成学习计划创建工作计划"})

// 更新进度
plan({request: "任务1.1已完成，更新进度"})

// 查询进度
plan({request: "当前计划进度如何？"})

// 归档
plan({request: "所有任务完成，归档计划"})
```

## 返回值

Plan agent 返回计划摘要，包含 change 名称、任务总数、完成数和任务列表。
