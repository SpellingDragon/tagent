# compaction-scheduler Specification

## Purpose

> **superseded（2026-11-15 契约同步核验）**：本规范描述的分层段压实调度器（按 L1 段数阈值自动触发 L1→L2、再按 L2 段数阈值触发 L2→L3 的 `Compactor` 与其串行跨分区调度）已退役，该类型与调度入口在 Go 树零定义。现行的时间线收敛是**按带晋升的三龄段折叠**：近期窗口内的段原样保留，中带段的过程细节折为一条带事件键票据的段折叠产物，老带段整段并入一条历史综述；物理有界走**退位**（水位之前已结事实搬迁出热层、仍按身份可读），不走段合并。本文件只作历史记录，不再承载现行规范命令。
>
> **勘误（2026-11-16，退位机制整体删除）**：上段「物理有界走退位」对**现行行为**的断言已被推翻——现行热层不搬迁，日志只追加，热层字节随历史增长，其增长是显式声明、单独拥有的关切（MUST NOT 被声称有界）；成本有界走**可寻址索引**：开档读入量与常驻索引条目。退役事实本身（分层段压实调度器已退役）不改写。
