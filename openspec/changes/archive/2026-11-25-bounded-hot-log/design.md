# Design：热盘有界 + 归档可读

## D0 层模型（2026-11-23 用户校准）

- **逻辑层（L）**：事实身份/顺序/不可变、checkpoint（安静点切面＋切片＋cut）、tail（cut 之后的逻辑区间）、恢复语义、按身份可读的承诺。逻辑层不感知字节落在哪个物理介质。
- **物理层（P）**：journal 帧（WAL 式 append-only）、派生索引（槽表/order）、original/ref 族、段轮转与封段、manifest 搬迁、热卷 GC、归档介质。
- **规则**：有界性（`hot_bytes` 平台）是 **P 的属性**；L 的语义与承诺 MUST NOT 因 P 的布局/搬迁而改变。物理层 MUST 随时兑现逻辑层的读取——归档是**可读存储的组成部分**，不是“逻辑上不存在”。
- **因此**：`checkpoint` 的空间（切片有界于开放项）是 L 的派生量，不是字节界；字节界只由 P 的保留窗/归档定义。`tail` 是 L 的区间；常规 boot 的 tail 必在热开段（切割时点守恒），跨档 tail 只属损坏恢复成本（`archive-tail-read`），不构成 L 语义变化。
- **承诺口径**：P1“已提交事实按身份可读”**逻辑上不变**；新增的是**物理层可用性契约**——归档介质属存储的一部分，其缺失/损坏＝存储损坏（具名拒绝），而非“事实不存在”。不再使用“修订 P1 措辞”的说法。

## D1 权威与现状

- 用户裁定（2026-11-22，A 档）为最高权威；现行“无界＝已接受成本”口径撤销。
- 基线：`bde7f394` 之后的新提交（实施时重核 HEAD 与工作树）。
- 既有事实：journal 帧含事实体；`originals`/`ref` 族存正文与引用；索引为派生（槽表 + `order.log`）。**01.101 实测：正文在事件 body 与 `blob:` 两处逐字节重复（95.87% 帧字节）→ 先立删除项 01.105（方向待裁），归档单位以单一化后构成为准。**

## D3 关键决策（先形式化，后固化）

- **有界判据**：`hot_bytes ≤ f(window_workload) + B_overhead`，`f` 为保留窗（按字节上限 `hot_log_max_bytes` 为主、时间窗可选）内提交量；`B_overhead` 含**两个** cut 间隔的写入量——最新 cut 段＋开段的上限（各至多一个间隔）；索引侧不进 `B_overhead`（归 `H`，防判据自消）。归档卷字节＝`g(历史量)` 显式声明。稳态平台锚为唯一验收判据；单点测量不作结论。
- **配置界与结构下限**：`hot_log_max_bytes` 是目标保留量；恒热集合（最新 cut 段＋开段＋索引侧）是结构下限 `H`，`configured = hot_log_max_bytes + 2×当前热段最大日志区间` 低于 `H` 时以下限为生效上限、`hot_over_budget` 置 1——界破形态仍是等待，不改切割时点。
- **切割原语（唯一时点，2026-11-23 用户裁定）**：切段与 checkpoint 是**同一事件**——`cut`（安静点 fence＋序号＋一次提交批）；逻辑层取状态切片，物理层取段边界与 manifest 提交。字节超界只**请求提前 cut**，MUST NOT 在非安静点封段；安静点长期不可达（在飞操作不落地）时容忍超界，以 `hot_over_budget` 当前未收敛区间状态（0/1）与告警具名上报——界破是活性问题的观测面，不引入第二切割形态。本条取代初稿“按阈值独立轮转”。
- **checkpoint 的结构地位**：cut 唯一时点意味着 checkpoint 的持续发生（cadence>0）是热盘有界的**结构前提**——没有 cut 就没有段界。未开归档时不新增任何依赖（checkpoint 按现状运行）；开启归档后 checkpoint 从“恢复优化”升格为物理有界的驱动者，其 cadence 是界的部署参数，文档与配置说明 MUST 如此表述，MUST NOT 宣称“关闭 checkpoint 不影响有界”。
- **段与搬迁水位**：封段＝一个 cut 间隔的完整帧集；封段索引（键→偏移）随段落在归档卷，热卷不为其付费。manifest 可搬集合＝段界 ≤ 倒数第二个 cut 的段；最新 cut 所在段与滚动开段恒热（元数据水位规则，不扫描段内容找锚）。
- **搬迁协议**：copy 为 `.tmp` 暂存名→fsync 归档→**manifest 原子提交**（generation 双文件 swap，陈述最终名与摘要）→`.tmp` 改名为最终名→删热段→收缩热索引；最终名只在陈述之后出现，无 manifest 而有最终名制品即损坏；任一步停止可恢复；manifest 是“哪些段在归档、其键域与摘要”的单一权威，陈述丢失或不可读 **fail-closed**（无最终名制品且无 manifest 属空归档态，有最终名制品而无 manifest 为损坏）。
- **定位读**：热索引命中→直读；未中→归档 manifest→段索引→读段；热卷与归档卷都未陈述该键→`ErrOriginalMissing`；归档存在但不可读→`ErrArchiveMissing/ErrArchiveCorrupt`（**不降级为不存在**）。
- **originals/ref 族**：与帧同段归档或按引用随段迁移；01.101 给出四族字节占比后择一，禁止两处各存一份（单一真相）。
- **配置面**：`archive_root`、`hot_log_max_bytes`、可选 `archive_max_age`；从未归档的根在无 `archive_root` 时＝今日行为（一个未封段），回退零 diff、旧机制不下线；已归档的根移除声明后归档键不可得，不属受支持回退（C6 形态二）。
- **与 checkpoint/tail 的层关系**：checkpoint 与 tail 属逻辑层（D0）；物理层为其让路——恒热集合由水位规则构造保证（最新 cut 段＋开段），搬段不改变 cut 语义/身份/顺序。恢复读法＝manifest 定位本代 cut→切片直读→重放开段。跨档 tail 回放降级为**损坏恢复**路径（安静点标记缺失/损坏→全日志回退，`archive-tail-read` 计入损坏恢复成本），不是常规 boot 形态。归档卷须在不同卷/配额域。
- **被否**：物理删除（推翻按身份恒可定位读取，B 档）；仅压开销（不达绝对界，C 档）；在热卷内压实（无覆盖负载下不减唯一数据量）。
- **完整性校验的边界（2026-11-23 裁定）**：帧 CRC 机制保留（真相的具名损坏依赖它）；被否的是**策略与加成**——整日志逐帧全校验（O(历史)/boot）、校验和链（Merkle 化）、派生索引双份冗余、每次读全校验、以段头自述摘要代替实算（自证结构，不防封段后损坏）。boot 校验量下界＝热窗字节（每字节至少读一次），manifest 的 sha256 是搬迁权威而非 boot 免读依据。
- **不复活**：`RetireFacts`/`relocate`/冷档探测谓词形态；搬迁以 manifest + 段自描述为唯一权威。

## D4 依赖与波次

- 01.101 实测 → 01.102–01.103 冻结 → 01.104 独立设计审 → 02 实施（02.201→02.202∥02.203→02.204）→ 03 消费与锚 → F。
- 04（CI 吞吐）的吞吐优化只碰 workflow 与 race_check，与 02/03 触碰集不相交，可全程并行；其稳定性前置（consumer 风暴隔离、restart 恢复通知等待、完成通知接受/认领的原子 handover）另触达测试夹具与 `assembly`／`runtime/state` 产品面，登记在 04 proposal/design/spec，不宣称本域只改 workflow。04.403 的真 CI 读数排全部写单收口后取。
- 共享面：`memory/ledger` 引擎文件编排者单写或串行；`api/config` 字段与解码同批。
- 波次仅汇报分组；解锁以叶证据为准。

## D5 完成判据

- **P1 有界**：S1 稳态平台锚（多代，热字节不随史增；分母含窗口工作量）；同锚机理断言：最新 cut 段与开段不在 manifest（恒热），全史封段数＝成功 cut 数；热卷常态仅余最新 cut 段＋开段。
- **P2 可读**：老键经归档逐字节相等；S2 损坏/缺失具名拒。
- **P3 单一权威**：manifest 单一、段自描述；新写事实与归档搬迁无第二份正文副本（旧构建写出的根中引用旁的历史副本属只读兼容面，不在此列）。
- **P4 崩溃安全**：搬迁任一切点中断后重开一致（无半段、无丢段、manifest 与热段一致）。
- **P5 零迁移**：无归档配置＝今日行为；开启后由 cut 事件封段（旧根即一个未封段）。
- **P6 成本归因**：热盘字节、归档字节、定位读延迟三类分别实测声明；不以归档增长冒充热盘有界。第四类**开档恢复成本**：开归档时，boot 的完整性校验与热索引重建 SHALL 有界于热窗（稳态归档段与归档索引按读校验，不预扫、不读索引内容；崩溃残留删除最后热副本前只对对应本代段／索引补验摘要）；从未归档的根未开归档时零 diff。
- **P7 承诺面**：每条可宣称性质（有界/归档可读/恒热）有 id＋条件句（成立条件＋失败形态）＋成对见证锚（正常绿＋故障可破）＋唯一 canonical 家；非 canonical 文档零复述（F3 逐句审计；强度词扫描仅作发现清单）。
- **P8 吞吐**：证明面零收缩（轮次/变异/包集不动），race 分片并集保真＋聚合 fail-closed；真 CI 读数前后对比（关键路径 < 原单 job 60%）。

## D6 非目标

- 不引入在线压缩/重编码作为独立目标（可作 02 的节流选项，不替代搬迁）。
- 不改事实身份、账本责任与恢复语义；不改 `pointReadLog` 窄口。
- 不承诺归档介质自身的多副本/容灾（部署层声明）。
