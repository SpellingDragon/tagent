# resource-bounds Specification（delta）

## ADDED Requirements

### Requirement: KV 本地存储条目驻留有界

本地 KV MUST NOT 无界常驻全部分片内容：内存驻留为**条目级**、有字节预算（淘汰单位=条目；分片快照仅为持久单位）；写屏障与原子落盘语义 MUST 保持；冷条目淘汰后按分片快照读回该键，读值 MUST 与未淘汰等价。

#### Scenario: 冷条目卸载后读取

- **WHEN** 条目缓存超预算淘汰冷条目，随后读取该键
- **THEN** 读值与淘汰前一致，且常驻字节不超预算

### Requirement: 事件读缓存有界

事件存储读缓存 MUST 有字节预算的淘汰；缓存 miss MUST 从既有持久段正确回读，MUST NOT 以全链扫描代替；重启加载 MUST 惰性——启动峰值 MUST 以进程级内存断言有界，MUST NOT 在启动时物化全量事件正文。

#### Scenario: 超预算淘汰

- **WHEN** 缓存注入超过预算的事件量
- **THEN** 常驻字节不超预算，任意事件仍可正确读回

#### Scenario: 重启后首次冷读

- **WHEN** 进程重启后首次读取一个未驻留的事件
- **THEN** 从既有持久段读回成功，启动时未物化该正文，启动峰值有界

### Requirement: 空闲地址回收

常驻消费地址在无在途段、无未收通知**且无未清交付义务（含 held(reason=retrying) 的重试间隙）**超过空闲 TTL 后 MUST 被回收且可幂等重建；有在途工作或未清义务的地址 MUST NOT 被回收。回收与虚胖告警 MUST 以具名计数与日志可观测。

#### Scenario: 空闲回收与重建

- **WHEN** 地址空闲超过 TTL
- **THEN** 地址被回收，新输入到来时 Ensure 重建并正常消费

#### Scenario: 在途或义务未清不回收

- **WHEN** 地址有在途段、未收通知，或交付待清谓词为真
- **THEN** 回收不发生

#### Scenario: 回收可观测

- **WHEN** 一次回收发生
- **THEN** 具名计数递增且日志含地址与原因，读者可核对该次回收

### Requirement: 装配侧观察与回放内存有界

装配根的观察面、回放注册表与已提交事实表 MUST 以事实窗口为界：事实窗口外的材料 MUST 按既有键/前缀从持久段回读，MUST NOT 随进程运行时长无界常驻；事实窗口内 MUST 有显式预算并被测试锁定。**未清交付事实（held/owed 活动集）MUST 驻留事实窗口内，MUST NOT 落到事实窗口外；DeliveryConsumer 持有的义务 MUST 恒驻事实窗口内**——该驻留是 01 恢复读面包含全部未清交付事实的机制。该面与 01 恢复共用，跨域集成测试归本域的 1.2a；进程级断言 MUST 由完整 300 轮长跑承担。

#### Scenario: 长跑后窗口有界

- **WHEN** 同一进程连续处理超出事实窗口的历史材料
- **THEN** 观察/回放/事实表的常驻条目不超过显式预算，事实窗口外仍可等价回读

#### Scenario: 未清交付事实驻留窗口内

- **WHEN** 存在未清 held/owed 交付义务且事实窗口预算收紧
- **THEN** 这些交付事实不被推到事实窗口外，恢复仍能读到全部未清义务（不另立第二份读路）

### Requirement: 冒烟内存门（口径已裁决：真占用）

完整本地冒烟（300 轮）的真占用堆增长 MUST ≤128 KiB/轮（强制 GC 后稳定常驻采样为判定数）；虚胖分量（已归还系统未收回）MUST 单独记录并设观测上限=**真占用门的 50%（64 KiB/轮）**，超限 MUST 记告警事实，MUST NOT 无限膨胀，但不作过关判据。

#### Scenario: 300 轮长跑

- **WHEN** 完整本地冒烟（300 轮）执行并以 GC 后稳定采样判斜率
- **THEN** 真占用斜率 ≤128 KiB/轮且测试 exit 0

#### Scenario: 虚胖可观测

- **WHEN** 运行时归还延迟使总量采样高于真占用
- **THEN** 差值作为虚胖分量单独记录，不判红，超观测上限时记告警事实
