# 04 公共消费者与门禁

父变更：`pr36-concept-convergence`。本域验证正式入口与真实生产消费者，检查测试是否能杀死缺陷，并将 CI 资源/时序问题与产品语义修复分线。

## 目标

- 枚举 SDK/CLI/宿主等正式消费者，验证常驻消费、send、通知和关闭不是仅在组件测试中成立。
- 检查正锚、负锚、非空转、竞态与重复运行证据，识别假绿和脆断言。
- 保持 CI 门禁覆盖，不通过删测试、缩小包集合或新增生产机制换取稳定。

## 边界与依赖

- **依赖**：消费 01—03 的修复产物与冻结验收面，不替其决定产品语义。
- **被依赖方**：各修复单的消费者锚、F2 全量门禁与最终放行。
- **接口面**：根包公共装配、Host/Run 正式入口、CLI/示例、CI workflows 与 `scripts/gates`。
- **禁止事项**：不直调 helper 冒充公共入口；不删除负向测试；不降低 race/CI 覆盖；不在 R1 写仓库或访问付费服务。
