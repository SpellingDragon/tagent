# 04 公共消费者与门禁任务

## R1 独立只读拷问

- [ ] R4.1 枚举正式公共消费者并运行目标测试，验证 send/通知/常驻实例/关闭的生产接线、正锚、负锚和非空转证据 —— 验证：报告附入口路径、完整命令、原始退出码、实际用例数与生产调用链；组件测试、helper 拒绝和测试手工接线不得充当消费者锚。
