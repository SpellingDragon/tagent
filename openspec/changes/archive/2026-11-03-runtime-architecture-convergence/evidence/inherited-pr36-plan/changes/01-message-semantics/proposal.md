# 01 消息语义

父变更：`pr36-concept-convergence`。本域审查并收敛 send 回执、通知结清、委派结果、拒收与待定问题，确保同一业务事实不被多个状态或名称分别解释。

## 目标

- 从公共入口追踪受理、事实落链、运输投递、逻辑消费与答复，明确每一步能与不能承诺什么。
- 验证通知不丢、拒收可见、委派结果与本次答复不错配。
- 优先删除平行读面与双重结清判据，不以新账本或新窗口掩住语义缺口。

## 边界与依赖

- **依赖**：只读 02 提供的地址与消费实例身份；接口依赖为现有地址/事件键，不依赖其私有实现。
- **被依赖方**：02 的关闭判据、03 的概念账、04 的公共消费者验收。
- **接口面**：`Host.Invoke`、正式 send/notice/delegation 入口、公开查询与关闭报告。
- **禁止事项**：不修改实例注册或关闭状态机；不新增通知/回执 capability；不直调 helper 冒充生产消费者；不在 R1 写仓库。
