# 03 概念与 API

父变更：`pr36-concept-convergence`。本域建立当前 PR 的概念账本与导出公共面差异，识别真正新增、真实删除、仅改名、双轨并存及权威地位变化，防止修复把局部机制升级为领域概念。

## 目标

- 以 `origin/main...dfdfa72e` 和当前源码为证据，列出核心概念及公共 API 增删改。
- 检查同一语义是否有多个字段、状态、注册表、读面或规格名称。
- 让必要机制内化，让独立领域事实保留；最终公共概念面相对基线净减。

## 边界与依赖

- **依赖**：消费 01/02 的语义裁定；依赖其事实定义而非实现形状。
- **被依赖方**：所有修复单的概念净减门与 F3 最终概念账。
- **接口面**：导出 Go 类型/方法/字段、公开规格、生成 API 文档与核心词汇。
- **禁止事项**：不按名称相似就断言重复；不为了减数删除独立事实；不把生成文档计数当作架构简单性的唯一指标；不在 R1 写仓库。
