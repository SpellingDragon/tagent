## 技术要点

1. 概念账至少含：名称、类别、领域事实、权威来源、生产消费者、相对 main 的变化、处置理由。测试与日志引用不制造第二使用方。
2. 对双字段、双返回值、多层同名读面逐一做反事实检验：删掉后哪条独立生产路径坏；若损坏路径全部经过该结构自身，则判为自证结构。
3. 检查主规格、活动变更残件与归档规格的生效边界；superseded 标记不能替代实际退出。
4. API 净减按语义面判断，不能只数导出标识符；若删除一个双轨但引入更多状态名，仍属失败。

## 风险与回退

- 大型 PR 全量导出 diff 噪声高 → 优先核心包和本 PR 新增面，再检查跨包消费者；未扫面必须明示。
- 必要实现细节不应被误删 → 区分私有机制与公共领域概念，私有简化以所有权和状态来源减少为准。
