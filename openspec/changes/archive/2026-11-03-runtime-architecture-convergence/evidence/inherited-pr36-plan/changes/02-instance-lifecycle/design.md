## 技术要点

1. 枚举全部实例注册集合与驱动入口，区分“每个集合各自唯一”和“每个语义地址全局唯一”；后者必须由单一权威结构承载。
2. 沿关闭调用链记录停止受理、停止拉取、在飞模型/工具、事实写入、会话释放与返回报告的先后，不以函数名推断行为。
3. 对关闭返回后继续写、重复 Ensure、停止后重入、崩溃恢复和跨地址串扰建立公共入口场景。
4. 多重 Resting/Drained/Outcome 只有在回答不同领域问题时才可并存；否则收敛为一个权威结果。

## 风险与回退

- 生命周期修复触及共享热点文件 → 后续按触碰集合单或串行，不与消息语义并行互踩。
- 时序测试可能偶然变绿 → 重复运行与竞态检测，并以可控屏障只在测试侧制造交错。
- 同一机制三次修复仍出关键缺陷 → 停线交用户裁设计，不继续叠补丁。
