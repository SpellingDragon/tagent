# 02 实例生命周期

父变更：`pr36-concept-convergence`。本域审查每地址常驻消费实例的唯一性、重入与关闭状态机，确保同一地址不会被两个驱动源推进，关闭返回与真实停止状态一致。

## 目标

- 明确地址、进程实例、执行代与消费实例的身份边界及唯一权威注册面。
- 验证停止受理、停止消费、停止写入、会话关闭与重开的顺序及负向路径。
- 合并重复的 resting/quiesced/drained 判据，不为测试时序新增生产窗口或屏障。

## 边界与依赖

- **依赖**：使用 01 裁定的通知结清事实；只依赖统一读面，不复制通知账。
- **被依赖方**：01 的消费身份、03 的概念/API 账、04 的关闭与竞态门禁。
- **接口面**：常驻 consumer/loop、Host/Run 生命周期、公开 Close 与重入入口。
- **禁止事项**：不重新定义回执语义；不保留双注册表；不以轮询或 sleep 作为正确性依据；不在 R1 写仓库。
