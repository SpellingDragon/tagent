## 五、偏离与自决

1. **偏离（断言纠正，非行为漂移）**：`RestoreState` 原有"零切点时审批书读请求文件"表述按核对改写为"取 boot restore，随后按整条 attention 流＋其上请求记录折叠"。理由：seated 书（`WithApprovalSeat`，生产恒设）的 `rebuild` 在 `a.seated` 分支不为链上无问题的文件 hold 落座（approval_store.go:924-930），hold 的真实来源是 `chain.bind`＋`foldRequestRecords`；文件仍被 `RestoreBoot` 读取（只用于落已持问题的裁决与移走过期）。原断言若保留，会把"文件是 hold 记录"写进契约。生产代码零行为改动（仅注释）。
2. **自决**：新增一个契约正锚（缺片条），派单只点名一个负锚——因该条款在包内无锚（零切点仅覆盖 ledger，seated book 无覆盖），注释将无牙。
3. **自决**：负锚选 `Decide` 的按身份读（features 写面内可及的真实按身份读；approval 实现不可改）；两腿（记录键/答键）都测，因两腿各自可被折成"从未存在"，且答腿的折法会让一次新裁决覆盖已落裁决（变异实测 `nil` 返回）。
4. **未勾** `changes/03-consumer-convergence/tasks.md` 的 03.302 行：不在写面白名单，且装配面（`assembly` 五锚）归 W4b 未收口，勾选留编排者。
5. 停止条件核对：无需改 assembly 接线（装配已按拥有者声明形态调用 `RestoreState`/`Bind`）；无行为漂移。
