# 03 · 消费者收敛（consumer-convergence）

## 边界与依赖

- **父变更**：runtime-coherence（依赖 02.205、02.206 通过）。
- **依赖**：02 的通用机制与正式入口证据；01 的三份契约；现行 `session-checkpoint-material`、`plugin-mounting` 主规格。
- **被依赖方**：04 放行。
- **接口面**：消费者切片语义、材料声明到分派的一致规则；不新增框架级接口。
- **禁止**：改持久格式无设计门裁定；删除仍有独立语义的收据/能力；把“统一”做成新中间层；改冻结归档与外来面。

## 范围

把投影/压缩、治理、材料声明分别收敛到 02 已证明的机制；协调者不再解释具体消费者业务；删除被替代的双解释与专用分支。压缩正文副本先判唯一来源/可定位副本，再决定删除。

## 完成定义

- 协调者与装配根不出现按消费者名的业务分支；依赖由拥有者关系或类型化声明表达。
- 治理、投影、压缩的恢复各有正式入口证据；历史仍按身份可读。
- 材料声明归一后驱动同一分派；六端口与兼容读法保留；Governor 等实际分派与声明一致。
- 删除清单逐项有替代证据与负锚；删除后原 spec 场景仍被覆盖。
