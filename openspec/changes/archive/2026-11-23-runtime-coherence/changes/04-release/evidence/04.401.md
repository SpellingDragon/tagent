### 同规则判定（贡献 vs builtin）

- **禁用**：agent 级 builtin 与 agent 级贡献共用同一 `plugins:` 声明语义（`-` 前缀、重名幂等、未知名具名拒）；run 级 builtin 与 run 级贡献同为具名拒绝（前者报 `run-level` 范围，后者见 §五 G1）。
- **换代**：run 级集（贡献＋builtin）同为进程作用域、跨代存活（§二乙）；agent 级实例（builtin＋贡献）随声明按代重解析。
- **重启**：每次 `Boot` 重挂 builtin 目录集；贡献须由调用方重新给出，采用记录代而非重发新代。
- **未结义务**：卸载拒绝的唯一判据在状态 seam（`runtime/state/checkpoint.go:209`），与实例来源无关——R7 同一判据覆盖 builtin（`TestDisabledBuiltinHandsOverItsObligations`）、贡献（新锚）、换代（`TestGenerationSwitchKeepsTheSameStateAuthority`）与无主切片（`TestPendingSliceIsRefusedByName`）。
- **失败清理**：Boot 自家工厂与调用者工厂同处一个工厂序列，失败路径同一（位置具名＋已完成产出不挂接）。
