# 01 · 契约与取证（contract-evidence）

## 边界与依赖

- **父变更**：runtime-coherence（依赖 01.101 启动门）。
- **依赖**：归档 `runtime-recovery-ideal` 的 CARRYOVER 与 design（只读）；`api/durable`、`memory/ledger` 现行契约注释；`session-checkpoint-material` 与 `plugin-mounting` 主规格。
- **被依赖方**：02、03 全部实施叶。
- **接口面**：本子变更只产出契约文档、反例台账与精确写面；不产生产品接口。
- **禁止**：改生产/测试实现之外的产品代码、主规格、CI、冻结归档；把静态反例写成已修；新增通用框架或第二套调度。

## 范围

复现或驳回审计静态反例；冻结四份契约：状态派生与切面覆盖、存储读取、插件装配、材料声明到分派。产出保留/合并/删除清单与每叶签发区，供 02/03 并行实施。

## 完成定义

- 01.101 的取证台账逐条给出“已复现 / 已驳回＋反证 / 设计差距”。
- 四份契约均写明输入、身份、幂等、失败语义、缺片语义、真实消费者、禁止副作用。
- 症状锚 S1 已存在且红；S2 以台账结论关闭或保留。
