# Design · 02 任务纵向贯通

## D1 各叶方案与取舍

| 叶 | 所选 | 被否候选与理由 |
|---|---|---|
| 02.201 点读 | 共享契约增加按身份读取；任务回执与治理尾读迁移；`TierFacts.Get` 已有点读复用 | 保持仅 `Scan`：已知键扫全族，成本错层；为审批另立专用读口：重复契约 |
| 02.202 索引 | 定位结果校验身份；失败回退权威顺序；只读视图不修盘 | 接受零偏移为“无前驱”：改变答案；读路径自动重建：只读承诺破裂 |
| 02.203 Boot 接线 | 贡献工厂改为组合（追加），`Boot` 转交调用者工厂；顺序固定、恰好一次、失败清理 | 再加一个 `WithPlugins` 实例：赋值覆盖；在 `Boot` 复制工厂内部逻辑：第二真相 |
| 02.204 任务 apply | 一份有类型 `applyRecord(record)` 同时服务在线与恢复；时钟/唤醒在外 | 在线 `applyCommitLocked` 与恢复 `foldLocked` 继续并存：两份解释 |
| 02.205 纵切 | 任务账户先于邮箱由装配关系声明；缺任务切片走全志/尾增量；样板覆盖 checkpoint＋尾部 | 协调者按切片名特判任务：每加消费者改协调者；缺片按空态：丢未决 |
| 02.206 审批 | 先提交裁决事实，再更新内存；三态（未提交/不确定/已提交镜像失败）；快照与查询同源 | 失败还原 `Status`：已提交镜像失败时制造反向不一致；只改快照判据：运行期仍分叉 |

## D2 签发区（实施前填写）

每叶：候选指纹；已证/已驳项；精确写面（含镜像测试）；接口/格式变化；真实消费者；正/负/消费者锚全名与命令；相邻回归；权限边界；独立设计审；回滚触发。

## D3 停止条件

- 点读需要改变 `FactLog` 公共签名且消费者超过本单白名单：停回设计门补签发。
- 审批修复需要改变“已提交事实不可撤回”或引入补偿事务：停，列替代。
- 任务纵切发现账本格式不足以表达未决：停，按 D4 记录取舍，不夹带格式变更。
