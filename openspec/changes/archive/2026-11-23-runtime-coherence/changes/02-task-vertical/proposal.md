# 02 · 任务纵向贯通与前置接线（task-vertical）

## 边界与依赖

- **父变更**：runtime-coherence（依赖 01.102–01.104 契约冻结）。
- **依赖**：01 的 `recovery-derivation-contract`、`durable-store-point-reads`、`plugin-assembly.md`；现行 `session-checkpoint-material`、`plugin-mounting` 主规格。
- **被依赖方**：03 全部收敛叶。
- **接口面**：共享持久点读语义；`Boot`/`Assemble` 贡献工厂组合；任务有类型 apply。
- **禁止**：改投影/压缩归属（03.301）、改治理切片（03.302）、改持久格式或安全时机而无设计门裁定、改冻结归档。

## 范围

先做存储点读与 Boot 贡献接线两个前置，再做任务在线/恢复同一解释与“任务—通知—checkpoint—邮箱”真实纵切，最后修审批失败一致性。每叶必须先让目标锚红或记录反证。

## 完成定义

- 贡献经正式 `Boot` 真实生效，工厂顺序与次数可观察，失败清理无残留。
- 任务在线与恢复共用一份解释；旧 checkpoint 缺任务切片时走授权兜底而非空态。
- 审批写失败后：快照不丢未决、重启不放行；结果不确定与已提交镜像失败分开处理。
- 纵向样板与审批锚在正式入口上通过，负锚具名。
