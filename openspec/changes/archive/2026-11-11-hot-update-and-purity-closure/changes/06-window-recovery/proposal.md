# 04-window-recovery 提案

## Why

两条实测事实 + 一条被证伪的方案，把范围顶到这里：

1. boot 的红不在恢复机制：同一代 boot 里票据装载毫秒级，而启动期读侧重建占绝对大头；
2. 四遍全量解码里三遍不属于 boot 事件的消费（观察表、向量播种、独立 landedSeq 扫描）；
3. 「窗口内重建」被第 12 轮证伪：提交序上不存在无损早停（存活原文可比任何旧产物事件更深——滚入输入），三个修复方向全部翻车。

## What Changes（裁定集 r45）

### 折叠锚（核心）

折叠瞬间是每会话**同步、一致性安全**的检查点时刻。产物载荷扩展为完整锚：

- 摘要正文（已有）
- 死亡名单 `Covered`（已有）
- **幸存者名单**（新增）：批次应用后的投影序键列表，含合成键的事实键指向
- seq 位点（自带）

锚的判别依据是冻结事件类型 `event.CompressProductType`；事实键的 ID 拼写只是身份文案，不作机制判别依据，也不进入模型上下文。

重启 = **锚载荷 + 回放幸存者边界之后的本链事件**。退路 = 全量走链。锚 = 该会话最新产物；从未折叠的会话退全量（天然短）。

### 持久化与派生态

链事件是语义真相，既有主人日志承担机械重做；checkpoint 是可由链重建的派生快照，不是第三真相。**r46：原「锚不接收任意外部状态、不提供通用注册钩子」由用户裁决取代（domain 12）**——框架提供状态接缝，消费者注册可恢复状态切片，框架聚合为统一 checkpoint 事实。真正不可推导的状态必须先建模为事件；快照只加速恢复，语义真相仍在链。

### 读侧退役（boot 只做自己的消费）

- 观察表退役：查询直读持久层（`TierQuerySource`），`StoreQuerySource`/`ObserveStore`/运行期 land 钩子连同接线足迹原子删除；
- 向量缝退役：检索向量腿改查询时候选现嵌入，`VectorSeam` 整型删除。

### 固定成本

- landedSeq 已并入走链（r44 ✅）；
- tier 打开懒校验（读到哪校验到哪）。

### 载体（不变 + 已知缺口）

快照保留、面封顶；时间纯度审计照做；**游标缺口改口为必须**——mergeDelta 全量重扫 ⇒ 无它 boot 不平坦，折叠锚后测量定方案（seq 元数据或单一 WAL 统一）。

## 边界

- 压缩策略零改动（冻结=策略：何时折/折什么/保留几段/分龄/身份语义；golden 随载荷扩展重生成）；
- 不落第二真源；C 终局否决；**D（快照装全状态）原否决由用户裁决取代（r46，domain 12 统一 checkpoint 事实族）**；
- 预算面/策略面保留（provider 窗/输出余量/长上下文/阈值/keep_recent）。
- 锚 boot 在 4.c1 与数据准确性前置完成前保持关闭；本变更完成时必须默认开启，否则不得宣布完成或归档。**r46：默认 boot 恢复路径由 domain 12 统一 checkpoint 收编（独立锚 boot 与票据退役）。**
