# 03 reflection-golden：长时反思闭环 golden（G4）

父变更：agent-instances-and-delivery（依赖：无——验证面，可与 01/02 并行；账目断言可在 02 后集成）。

## Why

长时反思闭环（多轮反思累积）是核心机制（Q8=a）但从未有实测保护：有界端到端测试仅覆盖单段机制，历史"长时测量记录"引用悬空（`docs/SMOKE-RESULTS.md` 全仓 git 历史从未存在）。裁定（Q13=a）：golden 入 CI 常规门。

## What Changes

- 脚本模型驱动 **30–50 轮反思循环** golden 测试，入 CI 常规门（墙钟分钟级）。
- golden 断言面（D11）：水位单调不回退、零重复消费、零资源泄漏、跨会话投递逐目标恰一次、重启后水位续接。
- 门脚本化（`tests/gates` 或 go test -run 常规位），红即阻 CI。

## 边界与依赖

- **依赖**：无强依赖；"逐目标恰一次"断言的账目读数在 02.4 落地后升级为账目直读（先行版本用事实计数等价断言）。
- **被依赖方**：F2（golden 门入全量门禁）。
- **接口面**：golden 测试夹具（脚本模型、反思节奏参数压缩）。
- **禁止事项**：不用真实模型/网络（R24 门控三态：无门 Skip 不适用——脚本模型无外部依赖）；不断言语义之外的行为（水位/消费/泄漏/投递/续接五面之外不加断言）。
