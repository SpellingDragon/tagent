# Design · 03 消费者收敛

## D1 各叶方案

| 叶 | 所选 | 被否候选与理由 |
|---|---|---|
| 03.301 投影/压缩 | 投影切片只表投影覆盖；压缩账户（判决/应答）归压缩消费者；协调者不特判两段 | 协调者继续按压缩事实修正投影覆盖：每加消费者再改协调者；把压缩正文内联进切面：第二真相（先判副本性质） |
| 03.302 治理 | 切片表有效态与尾序号；历史裁决按身份读链；`Bind` 归治理拥有者并由装配关系触发 | 锁存全史在切片：有界性丢失；读失败铸新请求：制造第二身份 |
| 03.303 材料 | 声明（时机/失败）归一后驱动同一分派；六端口保留；`Governor` 由管线实际裁决 | 删六端口：破坏安全时机与现行契约；让 `Governor` 只进私有列表不参与裁决：声明失真 |
| 03.304 删除 | 逐项列替代者、负锚与 spec 场景；删后全门禁 | 批量删除不留替代证据：行为丢失；以“无引用”单独作为删除理由：未证行为已被覆盖 |

## D2 压缩正文副本判定

`anchorEntry.Content` 先判定：若可由链上产物按身份定位重建，则是冗余副本，删除并以统一读回替代；若切面是唯一可读来源，则保留并在声明处写明独立需求。判定须有正反两例与恢复锚，不以“省一次读取”当理由。

## D3 签发区（实施前填写）

每叶：候选指纹；已证/已驳项；精确写面；接口/格式变化；真实消费者；三锚；相邻回归；独立审；回滚触发。删除项另填：被替代结构、替代证据、覆盖该行为的 spec 场景与测试、反事实（不删谁坏）。

## D4 停止条件

- 删除某项后仍有正式消费者依赖：停，登记为保留并说明独立需求。
- 收敛需要改变 `Material` 安全时机或六端口：停回设计门，列替代与全部消费者。
- 协调者去特判需要新增通用依赖调度器：停，优先由拥有者装配关系表达。
