- 用户目标与 2026-11-22 原话是最高权威；归档 `runtime-recovery-ideal` 的 design 与 CARRYOVER 是历史承接输入，不改写其文件。
- 真实 PR 基线：base `90fecc56`，当前候选 `52d7b664`；本变更实施时重核 HEAD 与工作树，不把候选 SHA 当永久环境。

证据等级沿用归档 design D1；本变更新增两类：

| 等级 | 含义 | 用途 |

## D4 关键设计选择与签发

| 决策点 | 所选 | 被否候选与理由 |
|---|---|---|
| 状态派生形态 | 每个消费者一个有类型 apply，输入为已提交事实；时钟/唤醒/观测留在外侧 | 全仓万能 `Reduce(evt)`：会把“谁解释哪些事实”摊给所有持有者，且无法表达消费者专属身份；否决 |
| 切面覆盖来源 | 每个切片自述覆盖范围；框架按切片判定，不借用投影进度 | “投影进度代表全部消费者”：新消费者缺片会被静默跳过；否决 |
| 缺片语义 | 无切片/缺片＝读该消费者所需历史或具名拒绝，不按空状态启动 | “缺失即空”：已证会丢未决工作；否决 |
| 恢复前置关系 | 由拥有者声明装配关系（如任务账户先于邮箱），协调者不解析业务 payload | 协调者按切片名特判：每加一个消费者就要改协调者；否决 |
| 存储读取形态 | 共享契约表达点读与扫描；优先复用既有 `Fetch{Key}` 能力 | 仅 `Scan(prefix)`＋消费者类型断言：已知键被迫扫全族；否决 |
| 索引失效 | 定位校验失败时回退到权威顺序或具名重建；只读视图不擅自修盘 | 索引答“无前驱”当作事实：改变答案；否决 |
| 插件接线 | 正式入口统一承接贡献与代际注册；工厂组合顺序固定、恰好一次、失败清理 | 追加第二个 `WithPlugins`：赋值语义会覆盖；否决 |
| 材料声明 | 归一后驱动同一分派规则；六端口与兼容读法保留 | 删除六端口或允许任意时机组合：破坏安全时机与现行契约；否决 |
| 压缩正文副本 | 先判唯一来源/可定位副本，再删冗余 | 直接删 `anchorEntry.Content`：可能破坏恢复；否决 |

实施签发在各自 design 的签发区填写：候选指纹、已证/已驳项、所选方案、精确写面、接口/格式变化、真实消费者、三锚、回归、权限边界、独立设计审、回滚触发。缺项则该叶 blocked。

## D5 完成判据与三级验收

### 定义完成判据（P0–P10）

- **P0 三挂点动态拓展（继承）**：特性经挂点/注册表挂载，装配根无特性硬编码。
- **P1 单一真相（继承）**：链唯一真相，一身份一不可变事实。
- **P2 单一状态派生（本变更主攻）**：每个消费者运行与恢复同一有类型 apply；切面覆盖与缺片语义自述；恢复零副作用。
- **P3 全部托管（继承，补审批/治理真实链）**：所有可恢复态经切片托管；有效态随开放项计费；历史按身份可读。
- **P4 成本归因（继承，补点读与索引）**：已知身份点读不扫无关历史；索引失效不改变答案；已接受 CRC 线性成本单列；未归因增长不记已接受。
- **P5 契约一致（继承，含 Material）**：主规格、代码、golden 同向；声明与实际分派一致；拒绝/故障具名。
- **P6 无死代码（继承）**：被替代的双解释、专用分支、伴生类型同批删除。
- **P7 模型自主消费（继承，不动）**：中段票据与 `recall_get` 行为不变。
- **P8 压缩可配置（继承，不动）**：摘要预算与租约行为不变。
- **P9 正式入口唯一接线（新）**：`Assemble`/`Boot`/reload 对贡献与代际注册同规则；工厂顺序、次数、清理有锚。
- **P10 放行证据（新）**：仅在冻结候选上采证据；CI 红项按原文归因；frontier 空才放行。

### 三级验收

1. 孙任务：三锚（正/负/消费者）exit 0，测试名与选择器逐字符一致，非空转。
2. 子变更：本域 spec 场景逐条映射到测试或命令。
3. 变更级 DoD：P0–P10 逐条有证据；S1 红转绿且回滚即红；S2 以阶段 0 结论关闭或保留反证。

## D6 历史、规格合并与承接

- 不改冻结 `openspec/changes/archive/**`；旧账以路径引用，不复制正文。
- 本变更承接：真实 CI/外部保护未绿；三观测轴与 total 增长终裁；file 档发现端到端；长期每代成本锚；13 条拒并与 #11 暂缓不自动关闭。
- 旧 R 编号不直接派发；新叶未完成起点，引用旧证据但重核行为。
- 主规格只在实施完成并归档时合并；本变更建立 capability 增量，不提前改主规格。

## D7 非目标

- 不新建通用依赖调度器、万能 reducer 或第二套运行框架。
- 不改变至少一次＋幂等消费语义、执行安全边界、事实不可变。
- 不要求不同类引擎等成本；只要求同能力透明包装不丢契约。
- 不实现 `no-prefix-criterion`，不吸收外来未跟踪面。
- 不以“接口数量减少”本身作为完成证据。
