## 三、Stateful 收编消费者读态（U2，依赖 U1）

- [x] 3.1 reducer 接入：每个消费者以 g(x) 纯派生面提供其读态，切面只陈述派生结果；delivery 第二派生路径（collectDeliveryRecoveryFact/restoreEventifiedDeliveries）收编为同一 Reduce（design D6.2）。验证：正锚＝`TestReducerDerivesEqualAtRuntimeAndRecovery`（`go test ./assembly/ -run TestReducerDerivesEqualAtRuntimeAndRecovery -count=1`，同一事实运行期与恢复期派生相等）；负锚＝`TestSnapshotFlushesNothing`（切面内 flush/commit/重入锁必红）；消费者锚＝`Run.Checkpoint`/`CheckpointSession` 经 StateRegistry.SnapshotState 纯读 reducer 输出。证据（U2）：三个消费者各有唯一 Reduce——`projectionStateSlice.Reduce`（assembly/checkpoint.go:1042）、`compressStateSlice.Reduce`（assembly/compress_consumer.go:468）、`deliveryStateSlice.Reduce`（assembly/host_delivery.go:1728）；运行期提交 `reduceCommitted`（assembly/facts.go:142，Reduce 调用于 152）与重建 `seedFact`（assembly/run.go:2938，Reduce 调用于 2949）同调 `StateRegistry.Reduce`，delivery 第二派生路径 `collectDeliveryRecoveryFact`/`restoreEventifiedDeliveries` 收编为 `replayDeliveryFacts`→`reduceDeliveryFact`。复跑：`go test ./assembly/ -run 'TestReducerDerivesEqualAtRuntimeAndRecovery|TestSnapshotFlushesNothing' -count=1 -v` → PASS（2 测试）。负向变异两发均红——(a) 切面内追加一条 committed fact → `TestSnapshotFlushesNothing` FAIL（"the cut left 13 committed fact(s) beside the 12 before it"）；(b) 恢复侧跳过 carrier 的 compress 切片还原 → 正锚 FAIL（"the booted rebuild holds 1 judgment(s) of session session-reducer-parity, want the 17 the live process holds"）；变异已回滚，复跑转绿。
- [x] 3.2 emitter 与 seedFact：observation 驱动者由声明提供，seedFact 复用 g(x) 派生而不另起路径（design D6.2）。验证：正锚＝`TestSeedFactReusesTheReducer`（`go test ./assembly/ -run TestSeedFactReusesTheReducer -count=1`，恢复后派生与运行期逐条相等）；负锚＝`TestRecoveryDerivesNoSecondTime`（恢复期额外派生一遍/第二路径必红）；消费者锚＝`seedFact`（run.go:2905）对注册 reducer 的消费者调 Reduce，emitter 一律不驱动。证据（U2）：`seedFact` 对注册 reducer 的切片调 `StateRegistry.Reduce`，emitter 由 `DrivesObservation` 声明、恢复期只由 `StateRegistry.ObservationDrivers`（runtime/state/checkpoint.go:273）报名字不驱动（assembly/run.go:2438 日志 "the rebuild folded the state slices of the chains it replayed and drove none of the observation drivers [compress]"）。复跑：`go test ./assembly/ -run 'TestSeedFactReusesTheReducer|TestRecoveryDerivesNoSecondTime' -count=1 -v` → PASS（2 测试）。负向变异：`seedFact` 对同一事实调两次 Reduce → `TestRecoveryDerivesNoSecondTime` FAIL（"the boot folded the fact single-derivation-6-3 2 time(s), want one derivation per fact"）；变异已回滚，复跑转绿。
- [x] 3.3 无新挂点：新消费者只注册切片即获得切面与恢复，框架不为单个消费者新增专用挂点或端口（design D6.2/D8）。验证：正锚＝`TestNewConsumerRegistersSliceOnly`（`go test ./assembly/ -run TestNewConsumerRegistersSliceOnly -count=1`，测试消费者只经 RegisterStateSlice 接入即获切面＋恢复）；负锚＝`TestNoPerConsumerDispatchPath`（出现按消费者名分派的专用路径必红）；消费者锚＝新消费者经正式装配入口 `Run.RegisterStateSlice` 接入，StateRegistry.Names 实测含其名。证据（U2）：`Run.RegisterStateSlice` 注册带 `Reduce` 的切片即获切面＋恢复，`StateRegistry.Reduce` 按 `reducer` 类型断言分派（runtime/state/checkpoint.go:261 `reduceInto`，无消费者名表），`StateRegistry.Names` 实测含 `assembly.new-consumer`。复跑：`go test ./assembly/ -run 'TestNewConsumerRegistersSliceOnly|TestNoPerConsumerDispatchPath' -count=1 -v` → PASS（2 测试）。负向变异：`StateRegistry.Reduce` 按名跳过 `assembly.no-dispatch` → `TestNoPerConsumerDispatchPath` FAIL（"the \"delivery\" consumer folded 23 fact(s) and the \"assembly.no-dispatch\" consumer folded 0, want the same set from the same facts"）；变异已回滚，复跑转绿。
