## ADDED Requirements

### Requirement: 等价对账仪器的判据完整性

注释/测试合并的等价判定仪器（`scripts/codetools` merge-check 与 comment-check）SHALL 满足：

- **文本归一止步于字面量**：任何对文本做归一的步骤——空白折叠、空行删除、行尾空白裁剪、限定符/别名致盲——MUST NOT 作用于字符串字面量内部。判据是**内容差异不得被归一吞掉**，不限于"空白"一种归一形式：凡把两侧文本抹平的归一器都必须知道字面量在哪里，否则一处未收口的归一器就足以让被改动的固件读起来未改动（假阴，危险方向）。
- **注释剥离覆盖全部注释槽**：行尾注释 SHALL 被剥离，且判定按**槽位类型穷举**而非按常见形态列举——声明行的行尾注释（类型定义、类型别名、import 项）与字段/值声明同属必须清空的槽，漏一个槽就把一次纯注释修改误报为正文变化（假阳方向）。
- **用法自述**：`--map`/`--explain` 的单值语义与"每包一次调用配自己的 map＋explain"的正确形态 MUST 写进用法行自述，因为误用是静默的（重复传参只留最后一个值）。
- **豁免边界声明**：explain 豁免只作用于非 Test 声明的边界 MUST 在台账中随 Test 类残留一并声明处置路径（补 map 行／换基线口径／另案定性），MUST NOT 以"登记 explain"冒充 Test 类缺口的修复。

仪器严格化之后 MUST 用同一批对**新旧两版仪器做 A/B 复跑**，证明新判据不追溯性推翻既有已声明的读数；若出现唯一差异，必须逐例定性并记录。

#### Scenario: 原始字符串内容变化不被归一吞掉

- **WHEN** 合并前后的两个测试在某反引号原始字符串内仅有空白差异
- **THEN** 等价判定 MUST 报告该差异，MUST NOT 因空白折叠把它判为相同

#### Scenario: 字面量内的键名变化不被别名致盲抹平

- **WHEN** 某固件字符串从 `agent.name` 改为 `other.name`，而代码里同一标识符的别名也被统一改写过
- **THEN** 等价判定 MUST 报告该差异；别名致盲只适用于代码位置的限定符，MUST NOT 伸进字面量

#### Scenario: 行尾注释删除不误报为正文变化

- **WHEN** 某类型声明仅删除行尾注释（如 `latencies []float64 // milliseconds` → `latencies []float64`）
- **THEN** merge-check MUST 判该声明 comment-only，MUST NOT 报 body-changed

#### Scenario: 判据严格化不得悄悄改写历史读数

- **WHEN** 仪器判据被收紧
- **THEN** 该批 MUST 以新旧两版仪器对同一批对复跑并报出新增项数，MUST NOT 只报"新仪器通过"
- **AND** 新仪器在历史批次上报出的每一项差异，MUST 定性为"当批已声明的真实改动"或"新发现的未声明改动"之一
