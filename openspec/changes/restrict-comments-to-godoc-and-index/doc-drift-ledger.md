# 注释 / 文档 / 实现 不一致台账

清注释时反复出现同一类问题：**注释（或文档）说的与代码做的不一致**。这类比"该删的废话"更危险——它会误导下一个改代码的人，而且**任何等价门都查不出来**（门只证明"没改代码"）。因此每批必须把撞见的记到本表，并三选一处置：改文档／改代码／记为待裁决。
