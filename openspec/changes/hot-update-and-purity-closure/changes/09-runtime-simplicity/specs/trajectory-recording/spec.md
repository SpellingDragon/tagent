## ADDED Requirements

### Requirement: 训练记录承载收敛
训练相关记录 MUST 复用执行事实与请求证据，MUST NOT 另建一套与事实链并行的默认采集通道。既有包装器可以保留为显式开启的调试手段，其默认关闭。

#### Scenario: 默认不产生平行记录
- **WHEN** 未显式开启轨迹转储而完成一次调用
- **THEN** 系统 MUST NOT 写出与事实链重复的独立轨迹文件
- **AND** 请求证据与执行事实 MUST 仍可导出

### Requirement: 记录口径可区分
导出的记录 MUST 标明其来源是运行时请求快照还是显式转储，读取方 MUST 能据此判断字段完整性。

#### Scenario: 混用来源被识别
- **WHEN** 数据集中同时含运行时证据与显式转储
- **THEN** 每条记录 MUST 携带来源标识
- **AND** 严格导出 MUST 拒绝缺少该标识的记录
