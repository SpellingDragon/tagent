# B 历史读取—派生索引

> 父变更：`runtime-recovery-ideal`。执行入口为 [ORCHESTRATION](../../ORCHESTRATION.md)；本轮只重整四件套，六个新叶均未执行。

## Why

长期重启变慢与旧事实读取成本，需要沿真实读取链归因。日志保留历史而物理增长是已接受目标，不等于查询、恢复及计量自身的重复工作也获豁免。旧方案的切片布局、探测界、内联正文和常开指标都只是待核实现，不作为本轮前提。

源码已否定“压缩产物 ID 包含 text”的内联理由，但还未证明所有生产者的产物都能由现有定位信息读回。129 个同桶 keys 仅构成算术反例，尚无真实存储入口实跑证据；全日志 CRC 的读时等价替代也未获证明。

## What Changes

- 先枚举身份、缺失、墓碑、校验、前驱、原文 scope、压缩产物、转换和指标自身成本，再构造最小反证。
- 按独立消费者与全部角色比较保留、最小修正、删并或替代；缓存和可重建多索引不自动构成多权威。
- 选择冻结后实施索引与读取语义；不预选新引擎，不为当前门数字再造计量机制。
- 核产物定位与原文入口，先迁等价锚再删无消费者面；保留原摘要字节、顺序、预算及原始来源。
- 在真实 Tier、查询、recall_trace、recall_get 和外部转换入口验证安全与全成本；未知增长留在本单元关闭条件内。

## 边界与依赖

- **依赖**：13.101 核目标与候选；06.102 消费 12.101 的提交/快照取证及 13.102 的能力结论。06.103 另依 12.102 设计签发，06.104 依 12.103 实现，06.105 依 12.104。共享身份、提交位置和失败分类是接口语义依赖，后两项是实现依赖；具体前置以本域 tasks 为准。
- **被依赖方**：A 单元消费存储原子结果、原序与读取失败语义；13.104 消费产物/召回能力，13.105 消费旧项与规格对账，13.106/F 阶段消费本单元独立审及完整成本证据。
- **接口面**：`AtomicStore`、`Tier`、事件身份/位置/发布状态、原文 scope 与完整性、压缩产物定位；精确字段、格式、依赖和文件在 design 签发区冻结，不预定布局或方法数。
- **禁止事项**：不恢复已裁删除的冷层、退位或 lifecycle；不以删 CRC 作性能负控，不先删未证明等价的安全防线；不把只读视图变成修复写者，不把存储损坏当缺失，不靠恢复重算模型补正文。
