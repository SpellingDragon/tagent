## 三、历史到当前的读取方式

活动单元被重写的旧四件套按manifest路径到快照中读；其相对链接保留原字节，需以原change路径语境解释。其余十域的原正文仍在各目录，页首历史提示只改变派发资格，不改变原勾选和条款。冻结archive只读。

执行13.101时建立逐子要求及到期阶段，13.105收齐到期实现/单元验证结果；结论取“兑现 / 已证重复并有承接 / 用户明确裁撤 / 未完成”，预定后置审验另标“待13.106或F阶段核销”。后置标记不关闭旧项，F4结束前逐项清零；新发现缺陷仍回到实现拥有叶。“符号不在 / 测试绿 / 没有第二使用方 / 旧叶已勾”单独不能作为关闭理由。漏项先补承接与设计门，不无声扩大实现单。
